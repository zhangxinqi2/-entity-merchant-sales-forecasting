# 数据说明 / Data

## 重要：仓库不包含真实商家数据

为了尊重商家隐私、比赛数据协议和平台规则，本仓库**不包含任何真实商家销量、商品名称、门店地址或参赛数据**。

仓库中可见的数据只有两类：

1. `data/sample/*.csv`：由 `scripts/generate_sample_data.py` 生成的合成示例，格式与真实数据一致。
2. `web/src/data/` 与 `web/public/data/`：由同一个脚本生成的合成演示数据，供前端仪表盘使用。

## 目录

```text
data/
├── sample/          # 可直接提交的合成示例 CSV
├── raw/             # 放置你自己的原始数据（已被 .gitignore 忽略）
└── README.md
```

## 单商品 CSV 格式

```csv
行业：烘焙行业  地址：示例市 · 演示商圈（合成数据）  商品名称：黄油可颂  商品ID：001_01
日期,平均售价,销量,日平均气温,节假日,打折
2025-01-01 00:00:00,18.20,120,15.1,否,是
2025-01-02 00:00:00,17.80,131,15.4,否,否
```

字段说明：

| 字段 | 含义 | 示例 |
|------|------|------|
| 日期 | 日期或日期时间 | `2025-01-01 00:00:00` |
| 平均售价 | 当日平均售价 | `18.20` |
| 销量 | 当日销量 | `120` |
| 日平均气温 | 摄氏度 | `15.1` |
| 节假日 | 是否节假日 | `是` / `否` |
| 打折 | 是否打折 | `是` / `否` |

第一行的 `行业`、`地址`、`商品名称`、`商品ID` 用两个或更多空格分隔，键值之间用中文或英文冒号分隔。

## 转换为你自己的演示数据

把 CSV 放进 `data/raw/`，然后运行：

```bash
python scripts/build_history_json.py --input-dir data/raw \
  --output web/public/data/products_history_data.json
```

如果要重新生成完整的合成数据（包括 `products.js`、`salesData.js`、示例 CSV 和箱线图）：

```bash
python scripts/generate_sample_data.py
```

## 使用真实数据前的检查

- 确认你有权把数据用于公开演示。
- 删除或替换商品名称、门店地址、手机号、订单号等可识别信息。
- 不要把 `data/raw/`、Excel 原文件或比赛材料提交到 Git。
- 发布前运行 `git status` 和 `git grep` 检查是否误提交了敏感内容。
